HAYMANI BUSINESS & LIFE OS - V2 (fixed build)

Includes the iPhone-ready PWA app, Haymani logo, Master Plan DOCX and Control Workbook XLSX.

DEPLOY
Upload the CONTENTS of this folder (not the ZIP, not the folder itself) to the root of your
HTTPS static hosting repository (e.g. GitHub Pages), replacing the old app files.
index.html must be at the published root. Open the URL in Safari, then Share > Add to Home Screen.

AFTER UPDATING
Open the app online once; the new version appears the next time you open it. If it still shows
the old version, close the app fully and reopen. Your data stays on the phone.

BACKUP
Records are stored locally on the phone. Use the down-arrow button (top right) to export a JSON backup
and the up-arrow button to restore one. Note: the Home Screen app and Safari keep SEPARATE storage,
so enter your data in the Home Screen app and back it up regularly.

UPGRADING FROM THE EARLIER PROJECT MONEY TRACKER
Existing projects and transactions are picked up automatically. Advances recorded on a project are
converted into one "Advance received" payment (only once).

PROJECTS
Each project has an Edit button (project list and project ledger). Fields: customer, name, quotation no., quoted price,
expected cost, advance received, start date, deadline and notes. The advance is kept as one linked payment in the ledger.

TRANSACTIONS
Open a project's ledger to edit (✎) or delete any transaction. Editing the advance payment also updates the project's advance.
